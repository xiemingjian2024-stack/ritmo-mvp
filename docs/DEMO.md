# RITMO Demo｜电脑与手机体验

[**打开 RITMO 在线 Demo**](https://ritmo-portfolio-demo.xiemingjian2024.chatgpt.site/)源码仓库私有，在线 Demo 独立公开，无需 GitHub 权限。

## 电脑直接体验

1. 在 Chrome、Safari 或 Edge 打开公开 Demo。
2. 切换「训练、方案、记录」。桌面显示手机样机，小屏进入移动布局。
3. 切换「健身房／家里」，查看对应推荐；应用方案或自由搭配动作。
4. PLAY 开始热身、力量与拉伸，点圆环暂停／继续；结束后看记录。

只看交互时，可用暂停弹层的跳过入口浏览阶段，不必实际跟练。

## iPhone 添加到主屏幕

1. 在 **Safari** 打开公开 Demo。
2. 分享 →「添加到主屏幕」。
3. 保留 RITMO 名称，点「添加」。
4. 从主屏幕图标重新打开，以独立网页 App 窗口体验。

不需要 Apple 开发者账号、App Store 或 IPA。仍需网络加载页面与媒体，不承诺离线冷启动。Safari 和主屏幕 App 的存储可能隔离，不保证出现相同方案与记录。

图标缓存、自动播放、锁屏与切后台恢复需真机验收；本次桌面检查不替代真机测试。

## Android

在 Chrome 打开 Demo，按浏览器提供的「添加到主屏幕」入口创建快捷方式。具体模式以系统与浏览器支持为准。

## 下载源码运行

需要私有仓库权限。GitHub **Code → Download ZIP**，解压并进入包含 `package.json` 的目录；不要双击 `index.html` 运行 React 源码。

安装 Node.js 22.12+ 的兼容版本后：

```bash
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

电脑打开 `http://localhost:4173/`。同一 Wi-Fi 下手机使用 `http://电脑的局域网IP:4173/`，需电脑与服务持续运行。日常体验使用 HTTPS 线上 Demo，不依赖你的电脑开机。

## 数据保存与演示范围

方案、循环、Session 与中断快照保存在访问者浏览器 `localStorage`，核心键为 `ritmo-demo-v3`。Demo 与个人版域名不同，存储互不读取。预置方案和历史样例用于展示，不代表用户真实训练；之后的修改只写入当前浏览器。

换浏览器、域名或重新添加主屏幕不等于迁移数据。「数据备份与恢复」仍在规划中，尚无已验收导入导出；清除网站数据会删除当前浏览器记录。

## 推荐演示路径

- 品牌：首次打开 → Logo O → PLAY → 3·2·1 → 执行圆环。
- 匹配：环境切换 → 推荐 → 方案三阶段清单。
- 控制：点圆环 → 暂停 → 参数／跳过／结束 → 继续原进度。
- 回顾：记录 → 正背切换 → 点击肌群 → 日历 → 已完成数据。

计次由预设节奏推动，不是运动识别；媒体的设计师视觉确认不等于专业教练审校。
